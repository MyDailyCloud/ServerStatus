# ServerStatus Data Server 架构重构规划

## 📋 项目概述

本项目旨在将现有的单体ServerStatus应用重构为基于清洁架构(Clean Architecture)的模块化系统，提高代码的可维护性、可测试性和可扩展性。

## 🎯 重构目标

- [x] 从单体架构迁移到分层架构
- [x] 实现依赖注入和接口抽象
- [x] 提供完整的配置管理系统
- [x] 实现Repository数据访问层
- [ ] 实现Service业务逻辑层
- [ ] 实现Handler HTTP处理层
- [ ] 重构WebSocket实时通信模块
- [ ] 达到60%以上的单元测试覆盖率
- [ ] 完善部署文档和脚本

## 🏗️ 新架构设计

### 目录结构
```
data-server/
├── cmd/server/           # 应用入口点
├── internal/            # 内部包，不对外暴露
│   ├── config/          # 配置管理
│   ├── models/          # 数据模型
│   ├── repository/      # 数据访问层
│   ├── service/         # 业务逻辑层
│   └── handler/         # HTTP处理层
├── pkg/                 # 可重用的包
│   ├── logger/          # 日志组件
│   └── utils/           # 工具函数
├── test/                # 测试文件
├── docs/                # 文档
└── scripts/             # 部署脚本
```

### 架构层次
```
┌─────────────────────────────────────────┐
│              Handler Layer               │  HTTP请求处理、路由、中间件
├─────────────────────────────────────────┤
│               Service Layer              │  业务逻辑、用例实现
├─────────────────────────────────────────┤
│             Repository Layer             │  数据访问、存储抽象
├─────────────────────────────────────────┤
│                Models Layer              │  领域模型、数据结构
└─────────────────────────────────────────┘
```

## 🔧 技术栈

### 核心依赖
- **Go 1.19+**: 主要编程语言
- **SQLite**: 主数据库
- **Redis**: 缓存和会话存储
- **Gorilla Mux**: HTTP路由器
- **Gorilla WebSocket**: WebSocket支持
- **Logrus**: 结构化日志
- **YAML.v3**: 配置文件解析
- **Testify**: 测试框架

### 开发工具
- **Go mod**: 依赖管理
- **Docker**: 容器化部署
- **GitHub Actions**: CI/CD
